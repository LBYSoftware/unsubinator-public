Unsubinator setup guide

← Back to Unsubinator

You'll create a free Google Cloud project so that Unsubinator can read your Gmail headers with your own permission. It costs nothing and doesn't need a billing account. Allow about ten minutes.

Your item ID for step 6 is: mokkckihdecngaghbheeecogajbpaahc

1. Download and unzip

  1. Download unsubinator-selfinstall-v0.2.8.zip and unzip it. You'll get a folder called unsubinator. Keep it somewhere permanent, because Chrome loads the extension from it.

2. Create your Google Cloud project

  1. Go to console.cloud.google.com/projectcreate, sign in, name it anything (for example "Unsubinator") and click Create. Ignore any free trial offers.
  2. With the new project selected, open the Gmail API page and click Enable.

3. Set up the consent screen

  1. Open Google Auth Platform and click Get started. Enter an app name (for example "Unsubinator"), choose your email as the support email, set the audience to External, add your email as the contact, tick the agreement and click Create.
  2. Go to Data access, click Add or remove scopes, tick (or paste) https://www.googleapis.com/auth/gmail.readonly, then Update and Save.
  3. Go to Audience, find Test users, click Add users and add your own Gmail address. Only addresses listed here can sign in.

4. Create the OAuth client

  1. Go to Clients and click Create client. Choose application type Chrome extension, give it any name, and paste mokkckihdecngaghbheeecogajbpaahc into Item ID. Click Create.
  2. Copy the Client ID it shows. It ends in .apps.googleusercontent.com.

5. Add your client ID and load the extension

  1. Open the manifest.json file in the unzipped folder with any text editor. Replace YOUR_CLIENT_ID.apps.googleusercontent.com with your client ID, keep the quotation marks, and save.
  2. In Chrome, go to chrome://extensions, switch on Developer mode (top right), click Load unpacked and choose the unsubinator folder.
  3. Check that the extension ID shown on its card is mokkckihdecngaghbheeecogajbpaahc. If it isn't, sign-in will fail with "bad client id".

6. Use it

  1. Click the Unsubinator icon (use the puzzle-piece menu to pin it) and start a scan. Google will say it hasn't verified the app. That's expected, because it's your own project. Click Advanced, then Go to Unsubinator (unsafe), and allow read-only access.

Good to know

  • Changes to a client can take a few minutes, sometimes longer, to start working. If you see "bad client id" and the extension ID is right, wait a little and reload the extension.
  • While your project is in Testing mode, Google signs you out about every 7 days. Just scan again and approve.
  • Chrome may warn about developer-mode extensions each time it starts, and it won't update the extension automatically. Check this page for new versions.
  • To remove access at any time, click Disconnect in the extension or visit myaccount.google.com/permissions.
